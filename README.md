# CPU.cpp
- An implementation of various CPU architectures.
- Particularly I'll be implementing 32-bit CPUs with an 32-bit instruction width.
- I'll be implementing CPU architecture found in chapter 7 (MicroArchitecture) in the Digital Design and Computer Architecture book by Harris and Harris.
- And also modern CPU architectures like
  1. superscalar
  2. VLIW,
  3. vector and array processors etc as I learn them in ETH Zurich's Digital Design and Computer Architecture course
